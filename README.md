# BVQ: Benchmarking and Validation & Verification of Quantum computers

Working repository for designing benchmarks and acceptance tests for quantum computer
procurement (buyer–vendor agreed test suite), with focus on spin-qubit devices.

## Contents

- [SOURCES.md](SOURCES.md): curated links to programs (DARPA QB/QBI, EuroHPC), standards,
  reviews, protocols, spin-qubit literature and software tools. Papers are linked, not stored.
